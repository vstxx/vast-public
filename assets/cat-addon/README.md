# Cat Addon artwork

The Vast-owned Cat Addon implementation and asset-generation tools are public, but the former artwork archive and all generated derivatives are intentionally excluded from this repository because no author, source URL, license, or redistribution grant was recorded.

Do not restore those files. A future artwork bundle must have documented provenance and a license that permits source and binary redistribution. The expected development commands remain in `package.json` for use with a properly licensed replacement.
