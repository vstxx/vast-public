LANGUAGE MODELS
No language model ships in this package. Models are downloaded on request from
Mozilla's public model storage and verified against the SHA-256 values in
catalog/models.json, which were taken from Mozilla's Remote Settings
"translations-models-v2" collection and cross-checked against Mozilla's model
registry. The models are published by Mozilla for Firefox Translations
(https://github.com/mozilla/translations, MPL-2.0 training and inference code).
This extension does not redistribute them; each user downloads them directly
from Mozilla's storage.

LANGUAGE DETECTION
Page language detection uses the browser's built-in chrome.i18n.detectLanguage
(Chromium CLD3); no detector code is bundled.
