(`1 MiB = 1,048,576 bytes`). The baseline and final machine-readable reports
are generated by `npm run distribution:size-audit`; the retained local reports
are `performance-results/distribution-size-audit-before.json` and
`performance-results/distribution-size-audit-after.json`.

## Implemented optimizations

| Change | Before | After | Saved | Risk | Verification |
| --- | ---: | ---: | ---: | --- | --- |
| Install Playwright Chromium with `--no-shell` and reject any shell entry | Chromium plus headless shell | one full Chromium, `headless=new` | 270.74 MiB raw | Low | manifest policy, tree audit, packaged Playwright navigation/screenshot/video self-test |
| Use the exact verified manifest browser path | profile/global discovery could diverge from the shipped executable | absolute bundled path under `PLAYWRIGHT_BROWSERS_PATH` | security/consistency | Low | path containment, SHA-256, size and packaged runtime checks |
| Replace Gyan FFmpeg full build with pinned Gyan 9.0 essentials build | 462.33 MiB combined | 195.89 MiB combined | 266.44 MiB raw | Medium | capability inventory plus functional encode/convert/trim/merge/probe/recording matrix |
| Stop duplicating renderer-only packages in production dependencies | 97.44 MiB logical modules and 36.62 MiB unpacked native canvas | 2.70 MiB modules and no unpacked tree | 94.74 MiB logical modules | Low | Vite build, PDF worker/viewer, 538 unit tests and 63 packaged app checks |
| Replace broad Playwright PyInstaller collection with its maintained hook and exact metadata | broad `--collect-all playwright` | targeted Playwright metadata/driver hook | 2.51 MiB | Low | packaged import, browser and video self-test |
| Keep broad yt-dlp collection | dynamic extractor inventory | unchanged by design | 0 MiB | Low | representative Youtube, Generic, Vimeo and TikTok extractors load from packaged EXE |
| Build portable before NSIS | final tree could lose `app-update.yml` | NSIS leaves canonical updater-ready tree | correctness | Low | release verifier requires approved `app-update.yml`; update ZIP structure check |
| Keep normal NSIS compression | benchmarked against `maximum` | 4-byte difference only | no material difference | Low | identical optimized payload benchmark; normal avoids extra build cost |

UPX remains disabled. The expected benefit did not justify antivirus false-positive,
startup and binary-reputation risk for a browser distribution.

## FFmpeg capability contract

The release validates `-buildconf`, formats, demuxers, muxers, encoders,
decoders, filters, devices and `ffprobe -version`. Functional tests cover:

- H.264 + AAC MP4 with faststart and metadata probing;
- thumbnail extraction and scaling;
- MP3, WAV, OGG/Vorbis, FLAC, Opus, AAC and M4A audio;
- WebM VP9 + Opus, MKV and AVI video;
- stream-copy trim, concat-demuxer merge and filter-complex merge;
- raw BGRA input used by page recording.

FFmpeg and FFprobe are resolved by absolute verified paths. The pinned archive,
its SHA-256 and the matching license/source-build notices are enforced by the
release workflow.

## Compatibility and packaged testing

The hardened packaged application passed all 63 application smoke checks,
including startup, normal browsing, cross-site session cookies, HTML fullscreen,
external-protocol approval, site permissions, screen sharing and cancellation,
target-blank and script popups, sterile OAuth popups, history, bookmarks, notes,
split view, downloads, public HTTPS PDF rendering, settings, themes, Video &
Audio normal startup/embed, Network Devices, automation and diagnostics.

The packaged Video & Audio executable separately passed:

- Python 3.13.14 and Playwright 1.62.0 startup;
- exact full Chromium discovery with `headless=new`;
- page navigation, screenshot and WebM recording;
- representative yt-dlp dynamic extractor loading;
- FFmpeg/FFprobe capability and functional media tests;
- normal embedded backend startup through Vast.

Additional passing gates: TypeScript lint, 538 node tests, zero high npm audit
findings in client and Relay, release audit, obfuscated build/performance budget,
fuse integration, updater/bootstrapper tests, update ZIP validation, release
package validation and Microsoft Defender scans of installer and portable.

The NSIS install/uninstall smoke was not repeated while an existing user-owned
`C:\Program Files\Vast` session was active; the task deliberately did not kill
that session. The installer artifact itself passed package, checksum, fuse and
Defender verification. Public Authenticode/timestamp and a real previous signed
release upgrade remain CI/release-machine gates.

## Remaining opportunities

### Safe and recommended

- Keep the audit and size budget in every release build.
- Re-evaluate the pinned FFmpeg archive only when the complete capability
  contract passes against a trusted replacement.
- Keep all locale files until Vast publishes an explicit supported-locale
  policy.

### Optional / future

- Measure electron-updater blockmap differential downloads in a signed staging
  release while retaining the verified full ZIP fallback.
- Build a reproducible FFmpeg binary from pinned upstream source with exactly
  the proven capability contract and license configuration.
- Profile PyInstaller imports over a broad packaged Video & Audio workload before
  considering further targeted exclusions.

### High-risk / not recommended

- Reusing Electron's private Chromium build as Playwright's browser.
- UPX-compressing browser, Python or media executables.
- Deleting Chromium locales without a product locale policy.
- First-launch downloads, system Python/FFmpeg fallback or arbitrary binary
  mirrors.
- Removing yt-dlp extractor data or Playwright driver resources based only on
  static import analysis.
